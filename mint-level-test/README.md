# 🌿 Ms. Mint's English Garden · 레벨 테스트

신규 상담 때 학생 옆에 앉아 노트북·태블릿으로 진행하는 **영어 레벨 테스트 웹앱**입니다.
파닉스 · 어휘 · 문법 · 독해 4개 영역을 아이 수준에 맞춰(적응형) 테스트하고,
AR / Lexile **추정 범위**와 추천 반이 담긴 🌸 성장 리포트를 만들어 줍니다.

> 본 결과는 상담용 추정치이며 공식 AR/Lexile 점수가 아닙니다.

## 🔑 Gemini API key 발급 방법

1. [Google AI Studio](https://aistudio.google.com)에 Google 계정으로 로그인합니다.
2. 왼쪽 메뉴의 **Get API key**(API 키 가져오기)를 누릅니다.
3. **Create API key**(API 키 만들기)를 누릅니다.
   - 프로젝트를 고르라고 나오면 **결제 정보가 없는 새 프로젝트**를 고르거나 새로 만드세요.
4. `AIza…`로 시작하는 key가 나오면 **복사**합니다.
5. 앱의 **⚙️ 정원 관리 → 새 key 입력**에 붙여넣고 **💾 key 저장 → 🔌 연결 테스트**를 누릅니다.
   "🌿 연결 성공!"이 나오면 준비 끝입니다.

> Google 화면의 메뉴 이름은 가끔 바뀝니다. 비슷한 이름의 버튼을 찾아 주세요.

### 🛡️ key 안전 수칙
- key는 이 기기의 브라우저에만 저장되고, 화면·백업 파일·AI 전송 자료 어디에도 나타나지 않습니다.
- 다른 사람에게 key를 보내거나 카톡·문자에 붙여넣지 마세요.
- 공개 주소(Netlify)에서 쓴다면, [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → 해당 key → **애플리케이션 제한사항 → 웹사이트**에
  `https://내사이트이름.netlify.app/*` 를 넣어 두면 다른 사이트에서 key를 쓸 수 없어 더 안전합니다.
- 기기를 바꾸거나 정리할 때는 **⚙️ 정원 관리 → 🗑️ key 삭제**를 눌러 주세요.

## 💸 무료 프로젝트인지 확인하는 방법 (꼭 확인!)

**결제 정보가 등록되지 않은 프로젝트의 key를 사용하세요.**
결제가 연결된 프로젝트는 무료 한도를 넘으면 요금이 청구될 수 있습니다.

1. Google AI Studio의 **API keys** 화면에서 key 옆의 요금제(Plan / 등급) 표시를 확인합니다.
   **Free(무료 등급)** 이면 OK. **Paid / 결제 사용 중(Billing)** 이 보이면 그 key는 쓰지 마세요.
2. 더 확실히 하려면 [Google Cloud 결제 관리 화면](https://console.cloud.google.com/billing/projects)에서
   해당 프로젝트에 **결제 계정이 연결되어 있지 않은지(결제 사용 중지됨)** 확인합니다.

### 앱이 무료 한도를 지키는 방법
- 학생 1명당 AI 호출은 **테스트가 끝났을 때 1번**이 원칙입니다. 문항마다 AI를 부르지 않아요.
- 하루 한도의 **90%** 에서 미리 멈춥니다. (기본: Flash 18회, Flash-Lite 450회)
- 기본 모델(Flash)을 다 쓰면 **가벼운 모델(Flash-Lite)** 로 자동 전환하고 "🍃 가벼운 모델로 판정"이라고 표시합니다.
- 둘 다 다 쓰면 AI 없이 **로컬 추정 결과**만 보여주고 "내일 오후 5시(한국 시간) 이후 AI 판정 가능"이라고 알려 줍니다.
  (Google의 하루는 미국 태평양 시간 자정에 바뀝니다. 한국 시간으로 겨울 오후 5시, 여름 오후 4시)
- Google이 "한도 초과(429)"라고 답하면 **다시 시도하지 않고** 그 모델을 오늘 하루 잠급니다.
- **⚙️ 정원 관리 → 💧 오늘 사용량**에서 남은 횟수를 볼 수 있어요.
- Google이 무료 한도를 바꾸면 **🤖 AI 모델과 무료 한도** 표에서 RPM(1분당)·RPD(하루) 숫자와 모델 이름을 고쳐 주세요.

## 🌱 사용 순서

1. **🏡 새 테스트** — 닉네임, 학년, 영어 학습 경력(개월), 이전 교재, 상담 메모를 입력하고 **🌱 테스트 시작**.
   - 이름·닉네임·상담 메모·이전 교재는 **AI로 보내지 않습니다.** (학년·학습 경력·점수만 전송)
2. **학생 화면(영어)** — 아이에게 화면을 보여 주세요. 한국어는 나오지 않습니다.
   - 순서: Phonics → Vocabulary → Grammar → Reading
   - **파닉스**: 아이가 단어를 소리 내어 읽으면 원장님이 **✅(맞음) / ❌(아직) / 🔁(한 번 더 읽게 하기)** 를 누릅니다.
     🔁는 점수에 들어가지 않습니다.
   - 답을 고르면 맞았는지 보여주지 않고 "Great job! 🌼" 같은 격려만 나옵니다.
   - **⏸ Pause** 로 언제든 멈출 수 있고, 시작 화면에서 **▶ 이어하기 / 🏁 여기까지로 결과 보기** 를 고를 수 있어요.
     창을 닫거나 새로고침해도 진행 상태가 남아 있습니다.
3. **🌸 성장 리포트** — 테스트가 끝나면 자동으로 열리고, key가 있으면 AI 판정을 받습니다.
   - **👪 학부모용**: 레이더 차트, AR·Lexile 범위, 영역별 강점·보완점, 추천 반, 원장 코멘트
   - **🌿 원장용**: 상담 메모, 문항별 응답, 틀린 skill, AI 지도 포인트, 사용 모델
   - **🖨️ 인쇄 / PDF 저장**: 학부모용만 A4 1장으로 인쇄됩니다. 인쇄 창에서 대상을 "PDF로 저장"으로 고르면 파일이 됩니다.
   - **💬 상담 요약 문자**: 학부모님께 보낼 3줄 요약을 만들어 줍니다. 고친 뒤 복사해서 보내세요.
   - **🤖 다시 판정**: 확인창을 거친 뒤에만 다시 호출합니다. (무료 사용량 1회 사용)
4. **🌼 꽃밭** — 테스트한 학생 목록 (닉네임, 날짜, 추천 반, AR 범위).
   🌷 다시 보기, 🗑️ 삭제, 닉네임 검색이 됩니다.

### 적응형 규칙 (참고)
- 시작 레벨: 예비초 L0, 1학년 L1, 2학년 L2, 3학년 L3, 4학년 L4 (학습 경력 24개월 이상이면 한 단계 위)
- 한 레벨에서 3문항 이상 풀면 확인: **80% 이상 → 위로**, **40% 이하 → 아래로**, 그 사이면 5문항까지 보고 그 레벨로 확정
- 독해는 지문(3문항) 단위로 확인합니다.
- 같은 레벨에서 2번 어려워하면 그 영역은 끝냅니다(아이가 지치지 않도록).
- 영역당 최대 10문항, 전체 40분이 지나면 남은 영역은 건너뜁니다.

## ✏️ 문제 고치는 방법 (`questions.js`)

메모장(Windows) 또는 텍스트 편집기로 `questions.js`를 엽니다. **한 줄이 한 문제**예요.

```js
// 어휘: 일반 객관식 — vocab(레벨, "세부기술", "질문", ["정답", "오답", "오답"])
vocab(2, "community helpers", "A ___ helps sick people.", ["doctor", "farmer", "baker"]);

// 문법 — grammar(레벨, "세부기술", "문장", ["정답", "오답", "오답"], "그림 이모지(선택)")
grammar(1, "plural -s", "I have two ___.", ["cats", "cat", "cates"], "🐱🐱");

// 파닉스 — phonics(레벨, "세부기술", "보여줄 단어")
phonics(3, "silent e (a_e)", "cake");
```

- **정답은 항상 보기의 맨 앞**에 씁니다. 화면에서는 순서가 자동으로 섞여요.
- 레벨: 0=K 초, 1=G1, 2=G2, 3=G3, 4=G4, 5=G4+
- 문제를 추가하려면 비슷한 줄을 복사해서 붙여넣고 글자만 바꾸세요. 문제 번호(`voc-L2-03` 등)는 자동으로 붙습니다.
- 학생 화면에 나오는 문장에는 **한국어를 쓰지 마세요.**
- 따옴표(`" "`), 쉼표(`,`), 대괄호(`[ ]`)를 지우지 않도록 조심하세요.
- 독해 지문은 `passage(...)` 블록입니다. 지문마다 작성자가 추정한 Lexile·AR 값을 적어 둡니다.
  **Journeys 교과서 본문이나 공식 AR/Lexile 지문을 옮겨 적지 마세요.** (저작권)

고친 뒤에는 주소 끝에 **`?test=1`** 을 붙여 열어 보세요(예: `index.html?test=1`).
⚙️ 정원 관리 아래 **🧪 자가 점검 결과**에서 "문제은행" 항목이 모두 ✅면 안전합니다.

## 🧪 점검 모드 (문제가 생겼을 때)

| 주소 끝에 붙이기 | 하는 일 |
|---|---|
| `?test=1` | 자가 점검: 무료 한도 보호, 적응형 규칙, AI 판정 흐름, 문제은행, 백업을 자동 점검 |
| `?mock=1` | 모의 모드: 실제 AI를 부르지 않고 샘플 판정으로 리포트까지 확인 (사용량도 기록 안 됨) |
| `?mock=429` / `?mock=403` / `?mock=net` / `?mock=badjson` | 한도 초과 / key 오류 / 인터넷 오류 / 응답 오류 때 안내 문장 확인 |

> 모의 모드의 AI 판정은 고정된 샘플이라 아이의 실제 답과 맞지 않습니다. 실제 상담에는 쓰지 마세요.
